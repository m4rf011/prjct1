# Grand Line HQ

An unofficial, responsive Blox Fruits companion website.

## Features
- Searchable fruit archive with rarity filters
- Multi-item trade calculator with illustrative starter estimates
- Activity preparation cards and progression guides
- Responsive dark navy and gold design

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Important notes
- Fruit data is a starter reference and may not reflect every current game update.
- Trade figures are illustrative estimates, not official or live market values.
- Activity cards are preparation guides, not a live event tracker.
- This fan-made project is not affiliated with Roblox or the Blox Fruits developers.

## Publish with GitHub Pages
Open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will provide the published URL after deployment.
